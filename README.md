# CloudPulse — Cloud Status Dashboard

CloudPulse is a dashboard project built using HTML, CSS, and JavaScript to practise frontend development and AWS cloud hosting.

## Current Features
- Dashboard-style user interface
- Interactive CPU utilization display using sample data
- Responsive styling

## Technologies Used
- HTML
- CSS
- JavaScript
- Amazon EC2
- NGINX
- Application Load Balancer (ALB)
- Auto Scaling Group (ASG) — configuration practice

## AWS Practice
- Hosted a static website on an EC2 instance using NGINX
- Configured an Application Load Balancer and target group
- Created an Auto Scaling Group and explored target-tracking scaling configuration

## Current Status
The dashboard currently uses sample data. Integration with real AWS CloudWatch metrics is planned as a future improvement.

## Planned Improvements
- Display actual EC2 CPU utilization using CloudWatch
- Retrieve AWS metrics through a secure backend using AWS Lambda and API Gateway
- Automate infrastructure deployment using AWS CloudFormation
- Add a dashboard screenshot
